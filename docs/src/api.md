# API

Функции API пакета разделяются на две категории: 
- собственно командный интерфейс Робота (API Робота); 
- вспомогательные функции для работы с sit-файлами, в которых задаётся начальная обстановка на поле и может быть сохранено её текущее состояние.

## Командный интерфейс Робота

Эти функции образуют программный интерфейс Робота и предназначены собственно для управления им. Именно эти функции должны использоваться при решении учебных задач.

```@docs
Robot
HorizonSide
move!
putmarker!
ismarker
isborder
temperature
```

## Вспомогательные функции для работы с sit-файлами

Эти функции предназначены для создания, загрузки, сохранения, отображения и редактирования обстановки. Они не входят в командный интерфейс Робота (в узком смысле) и при решении задач по его программированию, как правило, использоваться не должны. Исключение могут составлять функции show_sit и save_sit, которые позволяют соответственно отобразить и сохранить результат работы программы, запускаемой в режиме без визуализации (robot = Robot(..., animate = false)). Функция show_sit также может использоваться для контроля промежуточных результатов при отладке такой программы, а функция save_sit — для сохранения конечного состояния обстановки, например, при автоматизированном тестировании пользовательских программ.

```@docs
create_sit
save_sit
show_sit
show_sit!
edit_sit
edit_sit!
```
